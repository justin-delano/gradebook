A gradebook for teachers of grades 3 through 10.
It runs as a real program on Windows and macOS, and as an app you install from this page on a Chromebook.
It works with no internet connection, and every score stays in a file that belongs to you.

[Install it](./install.html) or [open the web app](./app/) and try it now.

## What it does

Grades are a grid of students down the side and assignments across the top, and you fill it in from the keyboard without reaching for the mouse.
Subjects and standards colour and filter that grid, so you can look at one standard across the whole class without building a separate view for it.

Report cards give you a page for each student and grading period: the course grade the assignments add up to, where the student stands on each standard, the grade you decide to give, and room for comments.
Trends draws the same information over time, for one student or for the class together.

Setup is where a class is described once at the start of the year: the students, the subjects, the standards, the assignment categories, and how those categories weigh into a grade.

## What it does not do

There is no account to make and no server to sign in to.
Nothing about your students is sent anywhere, because there is nowhere for it to be sent.
The one exception is Google Drive backup, which you turn on yourself if you want it, and which puts a copy in *your* Drive and nowhere else.
[How that works](./drive.html) is written out in full.

There is no save button either.
Every edit is written down as you make it.
